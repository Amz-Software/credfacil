$# Instruções do agente

Este projeto utiliza OpenSpec.

Antes de qualquer alteração, avalie se ela exige
planejamento ou especificação.

Utilize automaticamente as Skills do OpenSpec para:
- Implementação de novas funcionalidades.
- Alterações arquiteturais.
- Mudanças em APIs ou bancos de dados.
- Refatorações complexas.
- Alterações que impactem múltiplos componentes.

Para correções simples, não utilize OpenSpec.

Quando necessário:
1. Analise as especificações existentes.
2. Utilize a Skill openspec-propose.
3. Aguarde aprovação antes da implementação.
4. Utilize openspec-apply-change.
5. Valide o resultado.
6. Utilize openspec-archive-change ao concluir.

Não exija que o usuário invoque o OpenSpec manualmente.$
