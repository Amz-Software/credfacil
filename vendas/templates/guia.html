1. Fluxo do Sistema

Responsabilidades

O fluxo envolve duas funções principais: Vendedor e Analista. Cada etapa é executada por um responsável específico conforme indicado abaixo.

Vendedor
1. Solicitação do Crédito

O vendedor cadastra o cliente e cria a solicitação de análise de crédito no sistema.

Analista
2. Tempo de Análise

O analista avalia a proposta de crédito, analisando os dados do cliente para dar uma resposta.

Vendedor
3. Ler QR Code para Instalar Aplicativo

O vendedor apresenta o QR code para o cliente instalar o aplicativo no celular.

Analista
4. Confirmação da Instalação

O analista confirma que o aplicativo foi instalado corretamente no dispositivo do cliente.

Vendedor
5. Gerar a Venda

Após a confirmação da instalação, o vendedor gera a venda no sistema.

Fluxo Completo

Após a geração da venda, o sistema cria automaticamente as parcelas conforme o tipo de pagamento configurado. As parcelas podem ser acompanhadas no dashboard e seus pagamentos informados conforme recebidos.

2. Dashboard e Gráficos

Página Inicial (Dashboard)

A página inicial do sistema exibe um resumo completo dos indicadores e métricas da loja. Ela está organizada em seções para facilitar a visualização:

Resumo Geral
  • Total de Vendas
  • Total de Parcelas
  • Valor Total
Gráfico de Balanço

Visualização gráfica da distribuição percentual das parcelas por status (Pagas, Vencidas, Desativados).

Como Interpretar o Gráfico de Barras Horizontais
Entendendo o Gráfico
  • Barras Verdes: Representam as parcelas pagas (status positivo)
  • Barras Vermelhas: Representam as parcelas vencidas (requer atenção)
  • Barras Cinzas: Representam parcelas de clientes desativados
  • Valores nas Barras: Mostram o percentual de cada categoria
  • Eixo X: Vai de 0% a 100%, mostrando a proporção
Interatividade

Passe o mouse sobre as barras para ver detalhes no tooltip.

Responsivo

O gráfico se adapta automaticamente a diferentes tamanhos de tela.

Modo Dark

As cores se adaptam automaticamente ao tema claro ou escuro.

KPIs (Indicadores)

Os KPIs são organizados por categorias para facilitar a análise:

Categoria Indicadores Descrição
Parcelas Pagas Quantidade e Valor Parcelas que foram pagas com sucesso
Parcelas Vencidas Quantidade e Valor Parcelas que passaram da data de vencimento
Parcelas a Vencer Quantidade e Valor Parcelas que ainda não venceram
Clientes Desativados Vários indicadores Parcelas de clientes que foram desativados

3. Solicitações e Análise de Crédito

Criando uma Solicitação
  1. Acesse o menu "Solicitações" na página inicial
  2. Cadastre um novo cliente ou selecione um existente
  3. Preencha os dados do cliente (nome, CPF, telefone, IMEI)
  4. Crie a solicitação de análise de crédito
  5. Aguarde a análise do analista
Status da Análise
Aprovada

A solicitação foi aprovada e uma venda será gerada automaticamente.

Reprovada

A solicitação foi reprovada e não será gerada uma venda.

Pendente

A solicitação está aguardando análise do analista.

Cancelada

A solicitação foi cancelada e não será processada.

4. Vendas e Pagamentos

Gerenciando Vendas

Após a aprovação de uma solicitação, uma venda é gerada automaticamente. Você pode visualizar todas as vendas no menu "Vendas".

Informação Importante

Cada venda gera automaticamente as parcelas conforme o tipo de pagamento configurado. As parcelas podem ser acompanhadas individualmente e seus status atualizados.

Gerenciando Pagamentos
  • Informar Pagamento: Quando um cliente paga uma parcela, você pode informar o pagamento no sistema
  • Status das Parcelas: As parcelas podem estar: Pagas, Vencidas, ou A Vencer
  • Clientes Desativados: Clientes podem ser desativados, e suas parcelas aparecem em uma seção separada
  • Acompanhamento: Todos os pagamentos podem ser consultados e filtrados

5. Caixa e Financeiro

Gerenciando o Caixa

O módulo de caixa permite controlar as entradas e saídas financeiras da loja.

Entradas

Registre todas as entradas de dinheiro no caixa, como pagamentos de parcelas.

Saídas

Registre todas as saídas de dinheiro, como despesas e repasses.

Relatórios Financeiros

O sistema oferece diversos relatórios para acompanhamento financeiro, incluindo relatórios de vendas, solicitações e extratos de caixa. Acesse através do menu de relatórios.

Dicas Importantes

Mantenha os Dados Atualizados

Sempre informe os pagamentos assim que recebidos para manter o dashboard atualizado.

Acompanhe o Dashboard

Use o dashboard para identificar rapidamente parcelas vencidas que precisam de atenção.

Use os Filtros

Aproveite os filtros nas listagens para encontrar rapidamente o que precisa.

Relatórios Periódicos

Gere relatórios regularmente para análise financeira e tomada de decisões.
